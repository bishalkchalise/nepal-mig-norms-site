2. Current instruments, shares and shifters

Design. Reduced-form Godlonton–Theoharides shift-share, not a 2SLS: exposure Z_pt = M_p × W̃_pt with M_p = baseline permits per 1,000 (2011 population) and W̃_pt = standardised share-weighted destination index lagged two years; district + survey-year FE; DHS weights; district clusters.

Two non-interchangeable scalings coexist (see CLAUDE.md, HANDOVER.md §3(a)): M_rate × W_std in est/13_main.R, 13f, 36, 37 (the paper), and M_p0_std × W_std (z × z) in build/07, est/09, 13e, 17, and the admin scripts 41–56. The clean pipeline uses only the paper scaling (M_rate × W_std, magnitude = β × IQR(M)).

Share variants found in code. Census-2001 absentees; DoFE permit windows 2009–2011 (primary), 2009–2010 (est/37), 2010–2013 (est/39), 2012–2015 and 2009–2015 (admin scripts 41–56), 2013–2015 (est/27); 2013 stock (five district names fail to normalise — acham, argakhanchi, dadeldhuda, tehrathum, udaypur → missing population). 2015–2019 did not exist anywhere.

Shifter variants found. WBL 1.0 composite and eight domain scores (var/04); 7-domain working-age mean (est/37); outcome-matched domains (est/36); UN Women VAW policy index + variants full/lawpol/violemp (var/04b, mig-vaw-norms/00_setup.R); OECD SIGI (single wave, build skipped); V-Dem v2x_gencl (mig-vaw-norms/17); relative WBL Σ s (WBL_d − WBL_NPL) (build/10, output absent); lead/lag placebos (LAG_OFFSETS = 0,−2,−4,+2). WDI destination controls (7 series) are share-weighted and lagged (build/09). No exchange-rate series exists, so the Khanna et al. FX shifter is not constructed.

Treatment definitions. Headline: none (reduced form). est/17_2sls.R instruments husband_is_away with the male+female z×z shocks — the script was never run (its output file does not exist). Legacy compute_estimates.py instrumented ann_mig_rate with a 2001-share Bartik.

4. Result-export pipeline (before)

Each est/ script writes its own CSV with its own schema (main_horse_race.csv, gt_*_results.csv, court_main_grid.csv, sv68_*, …; ≈140 CSVs across folders). p-values and N are always present; dep-var means only in some; first-stage statistics only in the unrun 17_2sls.R. No spec-id convention, no build hash, no single website-safe file. Two review decks hold "interactive cube" CSVs (coauthor_review_deck_*/output/interactive_specification_results.csv) that are the closest thing to a website export.

6. Inconsistencies that affected the clean design

  1. 2011 wife-beating attitudes are gated by s824aa (0.8% yes) → est/13_main.R nulls the five items and wb_any but not wb_index_w, so the headline index regression in the legacy table includes 2011's near-zero values. Clean pipeline: 2011 excluded for all attitude outcomes; indices rebuilt.
  2. Wealth quintile absent in 2001 → the legacy complete-case controls silently dropped the 2001 wave (attitude regressions had N≈38k = 2006+2016+2022). Clean pipeline: wealth dummies with a "not collected" level absorbed by the 2001 wave effect.
  3. Trend specification differs across headline scripts: region trends (13_main) vs district linear trends (13f, 36, 37). Clean pipeline: region linear trends in the Full block (district trends would absorb most of the five-wave variation).
  4. p-value df for the channel test differs (nobs − k vs G − 1). Clean pipeline: G − 1.
  5. Intensity scale across windows: legacy M_p0 sums permits over the window, so longer windows mechanically inflate M. Clean pipeline: annual-average permits per 1,000 (β × IQR(M) is invariant either way).
  6. literate_bin defined two ways (>= 1 vs %in% c(1,2)); clean uses >= 1 (reads part or whole sentence).
  7. hiv_stigma_index_w is populated in 2001 although no stigma item exists (all-NA item replaced by 0 in make_index). Not used in the clean families.
  8. ethnicity is NA in every wave; params.yml lists it as a control. Not used.
  9. Upstream exposure columns in the analysis files (exposure_shock_*) are stale relative to any new window; they are dropped on load.

7. Data dependencies and missing data

  • Outside the repo: INSEC microdata, court corpus, NRB LG population, lg_master.csv, ward crosswalk (all documented in CLAUDE.md). The clean pipeline reads only the panels already built from them, so it runs from the repository plus the upstream data/clean/ tree.
  • DHS raw recodes are licensed and git-ignored; the clean pipeline does not need them (it reads the cleaned analysis files, which are themselves committed upstream — see the QA note on history).
  • Missing: exchange-rate series (FX shifter), census outcome panel, 2013-stock district fix, DHS variables never extracted (v739 control over earnings, v212 age at first birth, v626 unmet need, d110 injuries, d119 help-seeking, v717 occupation).

8. Minimum restructuring done

Nothing upstream was moved or edited. A parallel, self-contained clean/ tree was added: config-driven share/shifter/instrument builders, one estimation engine shared by both papers, per-paper thin wrappers, a website export with spec IDs and a build hash, a Python static-site builder, docs, a Makefile and a GitHub Actions workflow (at the repository root, the only place GitHub reads workflows). The legacy scripts, dated folders and paper remain the record of the earlier results; the clean results are regenerated and will differ in level from the legacy CSVs because of the default window (2009–2012 vs 2009–2011), the annual-average intensity, the retained 2001 wave and the uniform scaling.
